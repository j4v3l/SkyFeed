# SkyFeed 0.1.3 preview

This update makes aircraft cards easier to scan in Discord. Movement alerts
combine their evidence and uncertainty into one explanation. Interesting-aircraft
cards show the operator once, expand community classification names, and use a
consistent Open reference button. Aircraft and leader views use deliberate line
breaks, and altitude values include thousands separators.

Display preferences, alert matching, channel bindings, and existing controls
continue to work as before. The update also refreshes the pinned compression,
SQLite, Go builder, and QEMU dependencies. SQLite locking settings are unchanged.

## Upgrade

Back up SQLite before upgrading. This release adds no database migration.
Use the image digest attached to the GitHub Release, or update the pinned Nix
source to the release commit. Keep the previous image or Nix generation available
for rollback.

## Preview notes

Movement remains an inferred ADS-B trend. Community metadata matches require
independent verification. The target-host soak remains a v1.0 acceptance gate.
