# SkyFeed 0.1.0 preview

This is SkyFeed's first public preview: a local-first ADS-B Discord bot that can
also accept snapshots from administrator-invited community feeder agents.

The release includes the complete Discord command surface, responsive aircraft
and weather cards, inferred local-airport activity, watch and emergency alerts,
reports, moderation, optional enrichment, multi-feeder aggregation, Docker
Compose, and Nix/NixOS packaging.

## Install

```sh
SKYFEED_IMAGE=ghcr.io/j4v3l/skyfeed:0.1.0 \
  docker compose --env-file .env -f deploy/compose.yaml -f deploy/compose.local.yaml up -d
```

Use the image digest recorded on the GitHub Release when an immutable reference
is required. Images are published for `linux/amd64` and `linux/arm64` with an
SBOM, provenance attestation, vulnerability scan, and keyless signature.

## Important preview notes

- Back up SQLite before upgrading an existing installation.
- Community ingress is off by default and must remain behind a private mesh or
  authenticated HTTPS reverse proxy.
- Movement labels are inferred trends, not official airport events.
- plane-alert-db classifications are community metadata to verify, not proof of
  operator, passengers, mission, origin, or destination.
- The full 24-hour target-host soak remains a v1.0 gate.
