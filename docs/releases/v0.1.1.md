# SkyFeed 0.1.1 preview

This maintenance preview introduces SkyFeed's protected development and release
flow. Normal work lands on `dev`; a reviewed promotion pull request advances
`main`, and successful main-branch CI publishes the version declared in
`VERSION` exactly once.

The published Linux AMD64 and ARM64 images include an SBOM and provenance,
receive a high/critical vulnerability scan, and are signed with GitHub Actions
OIDC. Release tags are immutable pointers to verified main-branch commits.

The release also updates `github.com/klauspost/compress` to 1.19.2. There are no
configuration or database migration changes from 0.1.0.

## Install

```sh
SKYFEED_IMAGE=ghcr.io/j4v3l/skyfeed:0.1.1 \
  docker compose --env-file .env -f deploy/compose.yaml -f deploy/compose.local.yaml up -d
```

Back up SQLite before upgrading. The preview limitations documented in the
[project status](../project-status.md) remain in effect.
